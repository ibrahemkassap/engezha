## 01. الرؤية ونماذج العمل الثلاثة (Business Models)

تمت ترقية منصة **أنجزها (ENGEZHA 2.0)** من مجرد موقع خدمات برمجية تقليدي إلى **منصة إنتاج رقمي متكاملة (Digital Production & Delivery Platform)** تدعم ثلاثة محاور تشغيلية أساسية:

### أ. المنتجات والحلول الرقمية الجاهزة (Ready-Made Digital Products)
- كتالوج يضم **12 مشروعاً ونموذجاً حياً** قابلاً للتجربة والمعاينة التفاعلية فورياً (`/preview/[slug]`).
- تصنيف شفاف لحالة الإنتاج الهندسية لكل مشروع:
  - `ready_to_launch` (جاهز للإطلاق الفوري خلال 3-5 أيام)
  - `customizable` (قابل للتخصيص وإضافة هويات تجارية)
  - `requires_customization` (يحتاج تخصيصاً وربطاً تقنياً)
  - `under_development` (قيد التطوير والتجهيز)

## 02. الحزمة التقنية والهندسة البرمجية (Tech Stack)

- **Framework:** Next.js 14 (App Router, Server Components & Dynamic Route Handlers)
- **Language:** TypeScript 5 (Strict Mode)
- **Styling & Design System:** Tailwind CSS مع نظام ألوان داكن/فاتح فاخر (Dark/Light Mode) وهوية برمجية موحدة
- **Database & Auth & Storage:** Supabase (PostgreSQL + Row-Level Security RLS + Realtime)
- **Validation:** Zod v3
- **Email Notifications:** Nodemailer (SMTP Engine مع حماية ضد هجمات حقن الترويسات)
- **Icons:** Lucide React
- **Unit Testing:** Vitest (24/24 Tests Passing)
- **Typography:** Cairo (Arabic First مع دعم توجيه RTL أصيل وتوافق كامل مع الشاشات المحمولة)

## 04. خطوات التشغيل والإعداد المحلي (Quick Start)

### المتطلبات الأساسية:
- Node.js >= 18.17.0
- npm >= 9.0.0

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف البيئة وأضف مفاتيح Supabase وبيانات SMTP:
```bash
cp .env.example .env.local
```

### 3. تشغيل بيئة التطوير:
```bash
npm run dev
```

### 4. تشغيل الاختبارات وفحص الكود:
```bash
# تشغيل اختبارات الوحدة (Vitest)
npm test

# فحص المعايير والتوافق البرمجي (ESLint)
npm run lint

# بناء نسخة الإنتاج والتحقق من الصفحات الثابتة (68 مسار)
npm run build
```

## 05. ضمانات الجودة والأمان (Security & Quality Guarantees)
1. **Zero-Fabrication:** عدم وجود أي تقييمات زائفة أو أرقام غير حقيقية؛ المشاريع المعروضة نماذج توضيحية بهندسة كود حقيقية تعمل بدون تزييف.
2. **Mobile-First & Responsive:** توافق تام مع مقاسات الهواتف الذكية والأجهزة اللوحية دون أي إزاحة أفقية أو مشكلات محاذاة.
3. **Data Integrity:** تدقيق كافة المدخلات من جانب العميل والخادم عبر مكتبة Zod.
4. **Instant WhatsApp Routing:** إحالة العميل المباشرة لخدمة العملاء برقم الطلب المحدد مسبقاً لتسريع دورة البيع.
